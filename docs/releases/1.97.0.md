# Empeg Remote 1.97.0

Stable release of the Android modernization. Includes the features tested in beta 3, with no new search or playback changes.

## Download and install

[Download the latest stable release](https://github.com/Token-Eater/empeg-remote/releases/latest).

- Install `empeg-remote-1.97.0.apk` over any 1.97.0 beta to preserve preferences. One APK supports phones and tablets.
- For the original app or 1.97.0-dev, record your preferences and uninstall that app first because its signing key differs. This resets app settings, not music on the empeg.
- Allow installation from your chosen browser or file manager. This fork is distributed through GitHub, not Google Play.
- Connect to the empeg over a reachable network. Hijack with its HTTP interface enabled is required. Use discovery or enter the player IP manually.

## Included changes

- Android 15 installation, system-bar layout and notification compatibility.
- Separate command, playlist and display requests, with HTTP timeouts and expiry of stale queued work.
- Corrected parsing of Hijack notification status.
- Fixed blank lens-colour previews.
- About menu with app version, Android/device details and a Copy details button, also accessible from player selection.

The Discovery timeout preference only controls player discovery. It does not change the HTTP timeouts after connecting.

## Coverage and limitations

Development testing covered physical Lenovo tablets running Android 10 and Android 15. Beta 3 was checked on an Android 10 tablet emulator, an Android 15 phone-sized emulator and a physical Lenovo TB330XU running Android 15. No physical Android phone has been tested. Android 5/API21 is the declared minimum, not verified coverage of every Android version.

Search improvements are future work; this release retains existing search behaviour. Legacy lint warnings remain. Please report problems through GitHub Issues and include the report from About > Copy details.
